# KingdomMod v0.3.5 - Animated monarch reskins

## What's changed

### ReskinPack
- Fixes replacements being missed when a monarch starts on an idle frame, and
  walking frames reverting when vanilla animation assigns the next sprite.
  Matching frames are now reapplied in `LateUpdate`.
- Discovers newly spawned renderers every half-second, including monarchs
  created after scene initialization and renderers that become active later.
- Preserves each original sprite's pixels-per-unit and normalized pivot, with
  cached variants for same-named frames that use different scale or pivots.
- Distinguishes loaded PNGs from actual runtime matches in `Latest.log`.
  `Matched sprite 'name' ...` confirms an assignment; a scene summary lists
  loaded names not observed yet. Match messages appear once per name per session.
- Adds warnings for invalid images, duplicate names, and mismatched dimensions.
  Accepts both `.png` and `.PNG` file extensions.

### Pack assets and documentation
- Pack textures and generated sprites now survive scene transitions.
- Adds a ReskinPack guide and updates the sprite and mount documentation with
  animated replacement behavior and monarch troubleshooting.
- Replacement PNGs must still use the individual sprite's exact name, such as
  `player_armour_king_walk_0.png`, rather than the containing `sactx-...` atlas
  name. Each PNG contains one frame; unmatched frames remain vanilla.

## Installing or upgrading

Download `KingdomMod-0.3.5-x64.msi` below and run it over your existing install,
or select your Kingdom Two Crowns folder for a fresh installation. Close the
game before upgrading. The MSI builds the mods locally against your game and
downloads setup dependencies when needed.

For a sprite pack, put your own replacement PNGs under
`Mods/ReskinPack/pack/sprites/`, restart the game, and play the relevant animation.
Check `MelonLoader/Latest.log` for `Matched sprite` messages. Monarch and biome
variants may use different frame names.
