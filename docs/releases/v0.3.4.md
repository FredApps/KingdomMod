# KingdomMod v0.3.4 - Kingdom Two Crowns 2.4.2 compatibility

## What's changed

### Game update support (Kingdom Two Crowns 2.4.2, Unity 6000.0.66)
- Rebuilt against the 2.4.2 game. All loader Harmony patches apply and every
  bundled mod loads on the new version.
- **Fixes "INTERNAL FAILURE! Failed to Process UnityDependencies!"** after the
  game update. The game moved to Unity 6000.0.66; the installer now pins the
  matching MelonLoader UnityDependencies (SHA-512 verified).
- **Installer detects a stale interop cache.** It compares MelonLoader's recorded
  `GameAssemblyHash` with the live `GameAssembly.dll` and regenerates references
  automatically when the game has been patched, so upgrading just works.

### Example mods
- ChallengeDumper: `ChallengeData.customSwapData` was removed by the game; the
  dump now records `customBiomeObjectPools` instead.

### Tooling
- `tools\update-after-patch.ps1` enables online generation for the
  regeneration launch (so a new Unity version's dependencies can download) and
  restores offline mode afterwards.
- `tools\dump-classes.ps1` no longer fails when Il2CppDumper's trailing
  "press any key" prompt runs without a console.

## Upgrading
Run the new MSI over your existing install. If the game was updated, the
installer runs a one-time setup pass to regenerate references.

## Validation
- Regenerated interop against 2.4.2 and built Release with 0 errors.
- Launched the game: 13 mods loaded, 44 loader patches applied, no errors.
