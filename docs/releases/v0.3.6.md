# KingdomMod v0.3.6 - Reskin matching and render-order fixes

## What's changed

### ReskinPack
- Matches sprite names regardless of capitalization or surrounding whitespace,
  with a fallback for Unity's trailing `(Clone)` suffix. Explicit clone-named
  replacements take precedence; biome suffixes and frame numbers remain significant.
- Reapplies replacements before the game's `KingdomRenderPipeline.DrawCamera`
  method as well as in `LateUpdate`, catching sprite assignments made after the
  mod's animation update. Uses the game's custom render path, not Unity's
  built-in camera callbacks. Falls back to `LateUpdate` if the hook is unavailable.
- Refreshes unmatched-sprite lookup results so sprites named later can match.
- Loads PNGs from subfolders under `pack/sprites/` and warns when a filename
  looks like an atlas texture rather than an individual frame.
- Reports ReskinPack version 0.1.2 and the loaded DLL path at startup. Loaded
  PNG counts remain distinct from confirmed runtime sprite assignments.

### Diagnostics and documentation
- Adds `UserData/KingdomMod/logs/reskin-latest.jsonl`, overwritten each game
  start. Records loaded files, observed runtime sprite names, renderer paths,
  textures, dimensions, pivots, shaders, opacity, and matches. Output is buffered
  and capped; logging failures do not stop sprite replacement.
- Updates the ReskinPack, sprite API, and mount guides. Explains why multiple
  frames sharing a texture PathID is normal and why animation or atlas names
  cannot replace individual frame filenames.

## Installing or upgrading

Close Kingdom Two Crowns and run `KingdomMod-0.3.6-x64.msi` below over your
existing installation, or select the game folder for a fresh installation.
The MSI builds the mods locally against your game and downloads setup
dependencies when needed.

Put individual replacement images under `Mods/ReskinPack/pack/sprites/` and
restart the game. For example, `player_armour_king_walk_0.png` through
`player_armour_king_walk_7.png` are eight separate frames, not an atlas image.
The active monarch, campaign, and animation must actually use those names.

If images load but remain unchanged, include the full `MelonLoader/Latest.log`,
`UserData/KingdomMod/logs/reskin-latest.jsonl`, your pack, and the campaign/monarch
when reporting the issue. `Matched sprite` confirms a renderer assignment;
`Loaded` alone only confirms files were read.

## Validation

- Release solution build passed with zero warnings and errors.
- All 28 ReskinPack regression checks passed using a simulated engine boundary.
- A live game probe deliberately overwrote a cloned/case-variant sprite after
  `LateUpdate`; the native render hook restored the replacement, with the new
  texture and original geometry verified. Temporary test files were removed.
- Updated DLLs were deployed locally and the ReskinPack DLL hash verified.
- Local WiX MSI build passed. Product version, product icon metadata, and the
  staged ReskinPack implementation and diagnostic source files were verified.
- The reported modder's specific artwork has not yet been visually verified;
  these address likely matching and render-order causes, not a confirmed
  reproduction of every reported pack failure.
